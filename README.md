# Leon_pro — B2B-сайт с админкой

Оптовый каталог тарельчатых дюбелей, площадок под стяжку, якорных скоб и СВП:
каталог с фильтрами и поиском, корзина с минимальным заказом, заявка без онлайн-оплаты,
личный кабинет покупателя и админка с доступом ко всем параметрам сайта. я идиот 

**Технологии:** PHP 8.1+ и SQLite (база — один файл, MySQL не нужен). Без сборки и зависимостей,
работает на обычном виртуальном хостинге Timeweb.

## Что есть на сайте

| Страница | Файл |
|---|---|
| Главная | `index.php` |
| Каталог (разделы, поиск, фильтры по размеру и типу, сортировка) | `catalog.php` |
| Карточка товара (фото, характеристики, цена, документы) | `product.php` |
| Корзина и оформление заявки (минимум 5 000 шт., ИНН, город, согласия) | `cart.php` |
| Вход и регистрация по email или телефону | `login.php` |
| Личный кабинет: заказы, статусы, «Повторить заказ», реквизиты | `account.php` |
| О компании, Доставка и оплата, Оферта, Политика ПДн и любые новые страницы | `page.php?p=…` |
| Сертификаты, Контакты | `certificates.php`, `contacts.php` |
| Анимация логотипа | `logo.html`, файл `assets/logo-animated.svg` |

## Админка — `ваш-домен.ru/admin`

- **Заказы:** список с фильтром по статусу и поиском; карточка заказа, смена статуса с письмом клиенту,
  комментарий менеджера (клиент видит его в кабинете), правка состава, количества и цен.
- **Товары:** добавление, правка, копирование, скрытие, удаление; фото; документы к товару;
  цена, фасовка, кратность; «ходовые позиции» на главной; быстрая правка цен списком.
- **Разделы каталога:** названия, описания, картинки, порядок.
- **Документы:** сертификаты и паспорта качества, общие и привязанные к товарам.
- **Страницы:** визуальный редактор текста и редактор HTML-кода, создание новых страниц, пункт в меню.
- **Клиенты:** реквизиты, заказы клиента, сброс пароля.
- **Настройки сайта:** название, слоган, логотип, фирменный цвет, телефон, email, адрес, мессенджеры, карта,
  реквизиты ИП и банка, тексты главной, минимальный заказ, шаг количества, показ цен, пометка к ценам (например, «с НДС»),
  Telegram-бот для заявок, email-копии, SEO, код Яндекс.Метрики.
- **Администраторы:** смена пароля, добавление и удаление админов.

## 1. Загрузка на GitHub

1. На github.com нажмите **New repository**, задайте имя (например, `leon-pro`), лучше **Private**, нажмите **Create repository**.
2. Распакуйте архив `leon_pro.zip` у себя на компьютере.
3. Загрузите файлы одним из способов:
   - **Через сайт:** на странице репозитория нажмите **uploading an existing file** и перетащите *содержимое*
     папки `leon_pro` (не саму папку). Проверьте, что в репозитории появились файлы `.htaccess` и `.gitignore`.
     На macOS скрытые файлы показываются по `Cmd + Shift + .`. Если они не загрузились, создайте их через **Add file → Create new file**
     и скопируйте содержимое из архива.
   - **Через терминал (надёжнее):**
     ```bash
     cd leon_pro
     git init
     git add .
     git commit -m "Leon_pro: сайт и админка"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/leon-pro.git
     git push -u origin main
     ```

База данных и загруженные картинки в git не попадают (см. `.gitignore`) — они живут только на сервере.

## 2. Размещение на Timeweb (виртуальный хостинг)

1. **Версия PHP.** В панели Timeweb: *Сайты → ваш сайт → Настройки* выберите **PHP 8.1 или новее**.
2. **Загрузите файлы** в папку сайта (`public_html`) одним из способов:
   - **Файловый менеджер:** загрузите `leon_pro.zip` в `public_html`, распакуйте, перенесите *содержимое*
     папки `leon_pro` прямо в `public_html` (чтобы `index.php` лежал в `public_html`).
   - **Из GitHub по SSH** (включите SSH в панели):
     ```bash
     cd ~/ВАШ_ДОМЕН/public_html
     rm -f index.html            # заглушка Timeweb, если есть
     git clone https://github.com/ВАШ_ЛОГИН/leon-pro.git .
     ```
     Для приватного репозитория Git спросит логин и *токен* GitHub (Settings → Developer settings → Personal access tokens).
3. **Права на папки:** у `data` и `uploads` должно быть право на запись (обычно 755 уже подходит).
4. **Откройте `https://ваш-домен.ru/admin`.** При первом входе сайт попросит придумать логин и пароль
   главного администратора. Пароль по умолчанию отсутствует: администратора создаёт тот, кто первым откроет `/admin`, поэтому сделайте это сразу после загрузки.
5. **Заполните «Настройки сайта»:** телефон, email, адрес, часы работы, мессенджеры.
   Обзор в админке подсветит, что ещё осталось заполнить.
6. **Заявки в Telegram.** Админка → «Настройки сайта» → «Уведомления»: там пошаговая инструкция.
   Коротко: создать бота у @BotFather, вставить токен, написать боту `/start` (или добавить бота в группу менеджеров),
   нажать «Найти ID чата» → «Добавить» → «Отправить тест». Каждая новая заявка придёт сообщением со ссылкой на неё в админке.
   Копии писем клиенту и менеджеру на почту — по желанию: для этого создайте в Timeweb ящик `noreply@ваш-домен.ru`
   и укажите его в поле «Адрес отправителя писем».
7. **SSL.** Подключите бесплатный сертификат Let's Encrypt в разделе *SSL-сертификаты*.

### Обновление сайта
Если ставили через git: внесите изменения в репозиторий и выполните на сервере `git pull`.
База и загрузки не затрагиваются.

### Резервная копия
Всё содержимое сайта (товары, заказы, клиенты, настройки) хранится в папке `data`, картинки и документы — в `uploads`.
Регулярно скачивайте эти две папки, Timeweb также делает автоматические бэкапы.

## Безопасность
- Пароли хранятся только в виде хэшей; все формы защищены CSRF-токеном.
- Файл базы имеет случайное имя, а папки `data` и `inc` закрыты от доступа из браузера.
- В `uploads` запрещено выполнение скриптов, загружаются только картинки и PDF с проверкой содержимого.
- Админка закрыта от индексации, после 5 неудачных попыток входа включается задержка.

## Вариант: облачный сервер + Docker

Для облачного сервера Timeweb Cloud (или любого VPS) в проекте есть `Dockerfile` и `docker-compose.yml`:
PHP 8.3 + Apache и Caddy, который сам выпускает HTTPS-сертификат. База и загрузки хранятся в томах Docker
и не пропадают при обновлениях.

```bash
curl -fsSL https://get.docker.com | sh          # установка Docker (один раз)
git clone https://github.com/marka71190-boop/leonpro.git && cd leonpro
cp .env.example .env                            # SITE_ADDRESS=:80 — пока без домена
docker compose up -d --build                    # сайт на http://IP-сервера
```

Автообновление из GitHub (раз в 2 минуты, база и фото не трогаются):

```bash
chmod +x deploy/autodeploy.sh
(crontab -l 2>/dev/null; echo "*/2 * * * * /root/leonpro/deploy/autodeploy.sh >> /var/log/leonpro-deploy.log 2>&1") | crontab -
```

Домен: A-запись домена → IP сервера, в `.env` укажите `SITE_ADDRESS=leonpro.ru, www.leonpro.ru`,
затем `docker compose up -d`. Обновление: `git pull && docker compose up -d --build`.
Резервная копия базы и загрузок:

```bash
docker run --rm -v leonpro_leonpro_data:/d -v leonpro_leonpro_uploads:/u -v "$PWD":/b alpine \
  tar czf /b/backup-$(date +%F).tgz -C / d u
```

Платформа «Приложения» (App Platform) Timeweb Cloud не подходит: при каждом деплое она удаляет файлы приложения,
то есть базу и загрузки.

## Логотип

Файлы в `assets/logo/` — с прозрачным фоном, надпись нарисована кривыми (шрифт не нужен):
- `leonpro-mark-for-light-bg.svg/.png` и `leonpro-mark-for-dark-bg.svg/.png` — основной знак;
- `leonpro-horizontal-for-light-bg.svg/.png` и `…-for-dark-bg` — горизонтальный, для шапок и бланков;
- `leonpro-animated-for-light-bg.svg`, `…-for-dark-bg.svg` — анимация по кругу; `leonpro-animated-once-for-light-bg.svg` — один раз (стоит на главной).

## Реквизиты в текстах

В тексте любой страницы можно написать метку — сайт подставит данные из «Настроек сайта → Реквизиты»:
`{{реквизиты}}` — блок реквизитов, `{{продавец}}` — название ИП, `{{телефон}}` — телефон.

## Что заменить перед запуском
- Адрес склада, email и часы работы (пустые поля на сайте не показываются), перечень транспортных компаний на странице «Доставка и оплата».
- Цены, фасовку и фото товаров — через админку (без цены товар показывается «По запросу»).
- Тексты «О компании» и других страниц — через админку.
- Тексты **оферты** и **политики ПДн** — это черновики, их должен проверить юрист.
